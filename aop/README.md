# Spring AOP POC

A small project demonstrating Spring AOP and the different types of advice.

## Topics

- `@Before` 
- `@After`
- `@AfterReturning`
- `@AfterThrowing`
- `@Around`
- `@Pointcut`
- Aspect configuration and conditional activation
- Testing aspect behavior

## Structure

Each advice type has its own aspect class and tests demonstrating its behavior.
