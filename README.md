# POCs

Collection of small projects used to learn and experiment with different technologies.

## Modules

- [AOP](aop/README.md) - Aspect-Oriented Programming with Spring
- [Redis](redis/README.md) - Redis integration with Spring Boot

## Technologies

- Java 21
- Spring Boot 3.5.3
- JUnit 5
- Mockito

## Prerequisites

- Maven
- Docker (required for Redis/Testcontainers)

## Build and Test

```bash
mvn clean install
```
This builds all modules and runs tests.
